## Introduction
This branch make Web UI and Api Server work together.  
The Web UI is based on Vue 3, and the Api Server is based on Go 1.27.  

More Information(like api,cli,and else), please turn to the docs of `dev` or `main` branch.  

## Build
Please run `./build.cmd` or `./build.sh` to build the project.
